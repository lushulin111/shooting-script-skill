# shooting-script-skill（拍摄脚本生成器 Skill）

输入一个摄影风格词（日系 / 港风 / 夜景 / 欧美……），自动生成一份可直接执行的人像拍摄脚本：服装搭配、动作引导、拍摄地点与时间、器材与光线、构图、道具妆发、调色提示，并配套参考图生成规格。

## 能力

- 内置 16 个常见风格配方：日系、港风、欧美、夜景、胶片、韩系、森系、街头、法式、古风、暗黑、运动、亲子、情侣、毕业、商务
- 每个风格输出 8 大板块完整方案 + 3 套服装搭配 + 6-8 个动作引导（含模特引导话术与镜头表）
- 未收录的风格词按通用摄影逻辑兜底生成
- 附 4 张参考图生成规格（3 张服装搭配图 + 1 张 6 宫格动作示范图），内置负面提示词降低翻车概率

## 使用方法

在支持 Skill 的 AI 助手中安装本技能后，直接输入风格词即可：

```
拍日系
拍港风夜景
来组赛博朋克
```

输出：完整拍摄脚本 + 参考图。

## 目录结构

- `SKILL.md` — 技能核心指令（触发方式、执行流程、服装日常化原则、安全条款）
- `风格库.md` — 16 个风格配方卡
- `输出模板.md` — 脚本输出模板（镜头表、引导话术、器材降级规则）

## 设计原则

- **服装日常化**：所有推荐单品为普通人衣橱可及的基础款（白 T、牛仔、碎花裙等），每套附"替代品"
- **器材分级**：同一方案同时给相机版与手机版
- **口径统一**：产出以"摄影师"视角编写，不限定教学场景
